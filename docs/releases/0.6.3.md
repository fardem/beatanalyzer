# BeatAnalyzer 0.6.3

Fixes from the test of 0.6.2. All details are in the [CHANGELOG](../../CHANGELOG.md).

## What's new

### Quick zoom without flashing
- A click on another window (5 s / 15 s / 30 s / 60 s) or on *whole file* acts at once.
- A click on the window already shown waits 0.5 s for a second click before it goes back to the whole file.
- A double-click makes the window the default when a song loads. The view no longer flashes window → whole file →
  window.

### DaVinci Resolve window
- Cue marks and section changes only come from the web app. They now stand under one heading *From the web app*
  in *Adjust marker colours*. When the panel is collapsed, a thin line marks their two swatches.

### Smoothing and free-time music
- With strong rubato (classical music), free jazz or music without a fixed metre, set **Smoothing to 0 %**. Smoothing
  is made for a fairly steady grid and can set bar lines where the music has none. The tooltip of the slider (web app
  and Resolve window) and the READMEs say so in German, English and Turkish.

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP) and run `start.bat`.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve – needed for the new
   heading in the colour panel and the new tooltip.

## Known

- The Resolve window needs DaVinci Resolve **Studio**.
- BeatAnalyzer does not guess the genre: for rubato or free jazz, set Smoothing yourself. A suggestion from the
  analysis is planned for a later version.
