# BeatAnalyzer 0.6.3

Fixes from the test of 0.6.2. All details are in the [CHANGELOG](../../CHANGELOG.md).

- **Quick windows without flashing:** a click on another window or on *whole file* acts at once; the window already
  shown waits 0.5 s for a second click (double-click = default) before it goes back to the whole file.
- **Resolve window:** cue marks and section changes stand under one heading *From the web app*.

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP) and run `start.bat`.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve.
