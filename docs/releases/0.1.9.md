# BeatAnalyzer 0.1.9

Änderungen seit 0.1.8 – Zusammenführung mit der parallelen Entwicklung aus Google AI Studio. 0.1.8 bleibt
unverändert erhalten; alle Einzelheiten stehen im [CHANGELOG](../../CHANGELOG.md).

- **Zweites Modell `md_beat_this`** (Masked Diffusion) – **nur für nicht-kommerzielle Zwecke**, Lizenz
  CC BY-NC 4.0: <https://github.com/fosfrancesco/md_beat_this>. Wird von Hand installiert (siehe README).
- **Resolve-Fenster:** Modell wählen; für `md_beat_this` muss das Lizenz-Häkchen gesetzt sein.
- **Web-App:** Modell-Kacheln mit Lizenzfenster, einstellbarer ffmpeg-Ordner, Wellenform mit `20s`-Zoom, Lupe und
  verschiebbarem Rahmen in der Übersicht.

## Aktualisieren

1. Neue Version holen, `start.bat` starten.
2. In der Web-App **In Resolve aktualisieren** klicken, Resolve neu starten.
3. Nur wer `md_beat_this` nutzen will (nicht-kommerziell): nach README von Hand installieren.
