# BeatAnalyzer 0.6.4

The main changes after 0.5.1 – versions 0.6.0 to 0.6.4. All details are in the
[CHANGELOG](../../CHANGELOG.md).

## Highlights

### Song structure that hears the music
- Every bar is compared with every other by its **notes (chords)**, its **sound colour (instruments)** and its
  loudness. Section changes are found even when the chorus is as loud as the verse.
- **Parts that come back get the same letter** (A, B, A, B, C …) – in the web app, in the Resolve markers
  ("Section B ▲ +5 dB – Bar 33") and in the Audacity labels.

### Better tools for cutting
- **Insert and delete beats** – in the beat table, or Shift+click / Alt+click in the zoomed waveform. Undo comes
  before reset everywhere (beat table, folded bar); in the beat table both sit in the header of the *Action* column.
- **One main tempo everywhere** (tile, tempo curve, histogram) – parts counted at half or double speed no longer move
  it. The beat interval tile shows how much the grid wobbles ("Grid ± 4 ms").
- **MIDI export with a tempo map** – every click on its beat in a DAW.
- Band lanes switch between 1× and 2× height; help texts have **dots in the colours of the diagrams**.

### Player and waveform
- **Sample-exact metronome.** Song and metronome each have a speaker button (crossed out when muted) and a symbol –
  a note and a metronome – instead of a word. Mute the song to hear only the metronome.
- **Blue frame in the overview:** while you drag it, the playhead follows the mouse and you hear where you are
  (scrubbing, as in the free overview); playback goes on where you release it (left of the overview = start).
  Double-click on the frame plays from its left edge.
- **Quick zoom 5 s / 15 s / 30 s / 60 s:** a double-click makes the window the default when a song loads (shown bold).
  Another window acts at once; the window already shown waits 0.5 s for a second click, so nothing flashes.

### DaVinci Resolve
- **Colour swatches in Resolve's own marker colours**, so the window shows what Resolve sets.
- **Own colours for cue marks and section changes** (default yellow and purple), under one heading *From the web app*
  with some air above it – both only come from the web app.
- The marker JSON, the note of the first marker and the subtitle info block name **BeatAnalyzer and its version**.

### Smoothing and free-time music
- With strong rubato (classical music), free jazz or music without a fixed metre, set **Smoothing to 0 %**. Smoothing
  is made for a fairly steady grid and can set bar lines where the music has none. The slider's tooltip (web app and
  Resolve window) and the READMEs say so in German, English and Turkish.

### Security and clean-up
- The local server **only answers its own web app** – other websites open in the browser can no longer trigger an
  update, install the Resolve script or change settings. Uploads go to safe temp files; the song name stays as it is.
- Cleaner signal processing (zero-phase filters, no aliasing); the old stand-alone page and leftover development
  settings are gone.
- The release only carries `BeatAnalyzer.zip`; an installation of 0.0.3 / 0.0.4 (then called BeatThis) is updated
  once by hand with the ZIP.

### Fixed
- The song volume sometimes did nothing after a few plays.
- Three different tempos for one song (tile, tempo curve, histogram) – now one main tempo.
- Dragging the blue frame during playback threw the view back to the old playhead.
- The "straight eighths / swing" line was removed – it was never measured.

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP) and run `start.bat`.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve – needed for the colour
   panel, the version in the markers and the new tooltip.

## Known

- The Resolve window needs DaVinci Resolve **Studio**.
- The song structure is computed from the sound, not a musical analysis – listen before you rely on it.
- Very long files (DJ sets) take a moment after the analysis while the song structure is computed.
- BeatAnalyzer does not guess the genre: for rubato or free jazz, set Smoothing yourself. A suggestion from the
  analysis is planned for a later version.
