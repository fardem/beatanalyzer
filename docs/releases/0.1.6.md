# BeatAnalyzer 0.1.6

Änderungen seit 0.1.5 – Rückmeldungen aus dem ersten Test der Analyse in Resolve. Alle Einzelheiten stehen im
[CHANGELOG](../../CHANGELOG.md).

## Das Wichtigste

- **Kurze Texte im Resolve-Fenster.** Der Fortschritt heißt „Tasks“ und zeigt kurze Zeilen; die Erklärung unter
  „Subtitle Track“ ist eine Zeile. Wer mehr wissen will, fährt mit der Maus darüber (Tooltip).
- **Mehr Infos in der Marker-Notiz:** Takt, Beat, Zeit, Tempo und Confidence.
- **Ein Subtitle Track je Audiospur.** Liegt der Song in A1 und A2, gibt es „… (A1)“ und „… (A2)“; mehrere
  Vorkommen in derselben Spur stehen auf demselben Track, jeweils unter ihrem Clip.
- **Zurück in deine Timeline:** Hast du während der Arbeit eine andere Timeline geöffnet, zeigt Resolve sie danach
  wieder.
- **Modell von beat_this:** `install_and_run.bat` lädt es vorab. Klappt der Download nicht, steht dort warum und
  wohin die Datei von Hand gehört.
- **Aufräumen:** Auch abgebrochene Analysen hinterlassen keine Ordner mehr in `resolve_temp`.

## Aktualisieren

1. Alle BeatAnalyzer-Fenster schließen, die neue Version holen, dann **`install_and_run.bat`** starten (lädt das
   Modell vorab, falls es fehlt).
2. In der Web-App unter *Exportieren → DaVinci Resolve* auf **In Resolve aktualisieren** klicken.

## Bekannt

- Ob Resolve die verlangte Fensterbreite nach dem Öffnen annimmt, zeigt erst der Test (Konsole: „resized to …“).
- Die Web-App fällt weiterhin still auf die Browser-Analyse zurück, wenn der Server nicht antwortet, und ist nur
  deutsch. Das README beschreibt noch den Ablauf von 0.0.5.
