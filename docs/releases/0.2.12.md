# BeatAnalyzer 0.2.12

The main changes from the first version (0.0.1) up to 0.2.12. All details are in the [CHANGELOG](../../CHANGELOG.md).

## What BeatAnalyzer does

BeatAnalyzer finds the **beats, downbeats, tempo and time signature** of a song and puts them into
**DaVinci Resolve** as markers and subtitles. It runs locally: a Python server analyses the song with
**CPJKU beat_this**, a web app shows the result, and a script in Resolve places the markers – or runs the analysis
itself.

## Most important features

- **Analysis with beat_this** (MIT licence) on GPU or CPU, librosa as a fallback (0.0.1).
- **Markers and subtitles in Resolve** – one marker per beat on the clip in the Media Pool and on the song's clips in
  the Timeline, a Subtitle Track under the song; marker colours per beat and a remove button (0.0.2 – 0.1.6).
- **Analyse straight from Resolve:** select a clip, press OK – no web app needed (0.1.5).
- **Bar smoothing** (slider “Smoothing”, default 90 %) for an even bar grid in uncertain passages (0.1.1 – 0.1.5).
- **Optional model md_beat_this** – **non-commercial use only** (CC BY-NC 4.0), with a licence check box in Resolve
  and the web app (0.2.0).
- **More audio formats** (m4a/AAC, ALAC, Opus, WMA …) and **correct MP3 markers in Resolve** (0.2.3 – 0.2.4).
- **Web app:** detailed waveform with quick zoom, loop (section or whole song), separate song volume, exports for
  Resolve, Audacity, MIDI and CSV (0.0.1 – 0.2.10).
- **Languages:** web app and Resolve window in English, German and Turkish; all other program texts are English
  (0.1.0, 0.2.7, 0.2.12).
- **One-click update** from GitHub (0.0.2).

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP) and run `start.bat`. Coming from a version
   before 0.2.3: run **`install_and_run.bat`** once.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve.
