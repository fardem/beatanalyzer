# BeatAnalyzer 0.3.1

The main changes after 0.2.12 – versions 0.2.13 to 0.3.1. All details are in the [CHANGELOG](../../CHANGELOG.md).

## Highlights

- **New Resolve window:** clear sections, the two ways as tabs, the model as two tiles, notes in coloured boxes –
  in the colours of the web app (cyan = action and choice, amber = md_beat_this licence and questions, red =
  errors, green = result) (0.2.13 – 0.2.14).
- **Remove markers with feedback:** the window answers at once ("Removing BeatAnalyzer markers …") and stays locked
  until the work is done (0.3.0).
- **MP3 without encoder delay:** no false warning any more – the window says "no correction needed" (0.3.0).
- **FLAC with an ID3 tag:** the web app names the cause and the ffmpeg command to fix the file (0.3.0).
- **Start without an empty browser window:** the web app opens as soon as the server is ready (0.3.1).
- **Turkish:** Resolve terms stay English ("marker"); no doubled progress line (0.3.1).
- **README in English, German and Turkish** with new screenshots; the CHANGELOG is now English.

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP) and run `start.bat`.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve. Do not copy the script
   by hand – only the installer writes the BeatAnalyzer folder and Python into it.
3. Analyse MP3 songs again (or export their marker JSON again) so the JSON contains the MP3 offset, also when it
   is 0.

## Known

- The Resolve window needs DaVinci Resolve **Studio**; the free version does not allow script windows and file
  access.
