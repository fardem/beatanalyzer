# BeatAnalyzer 0.1.5

Änderungen seit 0.1.4. Alle Einzelheiten stehen im [CHANGELOG](../../CHANGELOG.md).

## Das Wichtigste

- **Analyse direkt aus Resolve.** Oben im Fenster gibt es zwei Wege:
  - **Ausgewählten Clip analysieren:** einen Audio-Clip im Media Pool auswählen, OK. Das Skript startet die
    Analyse unsichtbar im Hintergrund (ohne Server, ohne Web-App), zeigt den Fortschritt und setzt danach
    Marker und Subtitles. **Abbrechen** geht nur während der Analyse – bis dahin bleibt das Projekt unverändert.
  - **JSON laden:** wie bisher.
- **Regler „Glätten“ im Resolve-Fenster** (0 % aus … 100 % voll geglättet, Standard 90 %). Weg und Wert merkt
  sich das Fenster.
- **Marker auch auf dem Clip in der Timeline.** Liegt der Song in der offenen Timeline, bekommen auch diese
  Clips die Marker – den Clip muss man nicht mehr neu aus dem Media Pool ziehen. „BeatAnalyzer-Marker
  entfernen“ entfernt sie mit, Marker von Hand bleiben.
- **Standard „Glätten“ 90 %** jetzt überall (vorher 70 %).
- **Web-App:** Die Kachel Taktart springt beim Verstellen des Reglers nicht mehr.

## Aktualisieren

1. Alle BeatAnalyzer-Fenster schließen, die neue Version holen (Update in der Web-App oder ZIP), dann
   `start.bat` starten.
2. In der Web-App unter *Exportieren → DaVinci Resolve* auf **In Resolve aktualisieren** klicken. Das Fenster
   zeigt danach „BeatAnalyzer 0.1.5“ im Titel.

## Bekannt

- Die Analyse aus Resolve ist nur gegen einen nachgebauten Resolve getestet. Ob Python unter Windows ohne
  Fenster startet, ob der Regler im Resolve-Fenster erscheint und ob die Marker auf einem vorne getrimmten
  Timeline-Clip an der richtigen Stelle sitzen, zeigt erst der Test in Resolve (`docs/resolve-test-tp3.md`).
- Die Web-App fällt weiterhin still auf die Browser-Analyse zurück, wenn der Server nicht antwortet, und ist
  nur deutsch. Das README beschreibt noch den Ablauf von 0.0.5.
- Das Resolve-Skript braucht DaVinci Resolve **Studio**.
