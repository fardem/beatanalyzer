# BeatAnalyzer 0.6.2

Fixes and wishes from the test of 0.6.1. All details are in the [CHANGELOG](../../CHANGELOG.md).

## Highlights

- **Drag the blue frame while the song plays:** playback goes on from where you release the mouse (left of the
  overview = start). Double-click on the frame plays from its left edge.
- **Default quick window:** double-click on 5 s / 15 s / 30 s / 60 s – that window is shown whenever a song loads.
- **Song and metronome** are muted the same way (crossed-out speaker) and show a symbol instead of a word.
- **Folded bar:** undo before reset, as in the beat table.
- **Resolve window:** colour swatches in Resolve's own marker colours.

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP) and run `start.bat`.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve – needed for the new
   colour swatches.
