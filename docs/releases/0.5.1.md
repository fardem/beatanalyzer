# BeatAnalyzer 0.5.1

The main changes after 0.2.12 – versions 0.2.13 to 0.5.1. All details are in the [CHANGELOG](../../CHANGELOG.md).

## Highlights

### Web app – built for cutting
- **Song structure:** level per bar over the whole song; where the song changes (intro → verse, build-up → drop,
  chorus → break) a section change is marked on its "1" – ▲ louder, ▼ quieter, ◆ different. Click or swipe the
  section buttons to jump there (0.5.0 – 0.5.1).
- **Cue marks while listening:** key **M** sets a cue on the nearest beat, **Shift+M** on the nearest "1". Cues and
  section changes go to Resolve as **yellow** and **purple** markers and into the Audacity labels (0.5.0 – 0.5.1).
- **Live view:** bar counter with the beats of the bar and the next section, live spectrum with a flash on every
  beat (0.4.0 – 0.5.1).
- **Check and fix the grid in one click:** band lanes for kick, snare and hi-hats; the **folded bar** shows whether
  the kick sits on the "1"; fixes for bar start (±1 beat), half beat, tempo ½× / 2× and beats per bar (2–7), with
  undo – for the whole song or only a section. A **suggestion** tries the fixes and offers the best one with a
  preview. Fixes survive Smoothing and go into every export (0.4.0 – 0.4.1).
- **Tempo** curve and histogram side by side (0.5.0).
- **Your own view:** fold the panels you do not need and drag them into your order; the web app keeps the layout
  (0.5.0).
- Help texts of all diagrams written for cutters: what does it mean for my cut? (0.5.0)

### DaVinci Resolve
- **New Resolve window:** clear sections, the two ways as tabs, the model as two tiles, notes in coloured boxes – in
  the colours of the web app (0.2.13 – 0.2.14).
- **Remove markers with feedback:** the window answers at once and stays locked until the work is done (0.3.0).
- **MP3 without encoder delay:** no false warning any more – "no correction needed" (0.3.0).

### Installation and start
- **NVIDIA graphics cards are used on Windows:** the installer now puts in the CUDA build of PyTorch (2.8.0, CUDA
  12.8 for RTX 50 cards, 12.6 for older drivers, otherwise CPU); a CPU build from an older installation is replaced
  (0.3.2).
- **No empty browser window at start:** the web app opens as soon as the server is ready (0.3.1).
- **FLAC with an ID3 tag:** the web app names the cause and the ffmpeg command to fix the file (0.3.0).

### Languages and docs
- Turkish: Resolve terms stay English ("marker", "beat") (0.3.1, 0.4.0).
- **README in English, German and Turkish** with screenshots; the CHANGELOG is English.

## Updating

1. Get the new version (update in the web app, `update.bat` or the ZIP). Coming from 0.3.1 or older on Windows with
   an NVIDIA card: run **`install_and_run.bat`** once, so the CUDA build of PyTorch is installed. Then `start.bat`.
2. In the web app: *Export → DaVinci Resolve* → **Update in Resolve**, then restart Resolve – needed for the yellow
   and purple markers. Do not copy the script by hand.
3. Analyse MP3 songs again (or export their marker JSON again) so the JSON contains the MP3 offset.

## Known

- The Resolve window needs DaVinci Resolve **Studio**; the free version does not allow script windows and file
  access.
- The section changes come from the levels of the song, not from a musical analysis – listen before you rely on
  them.
- Panel layout and bar counter are kept per browser.
